# 打開紫微斗數互動介面

用用家嘅語言（廣東話或者台灣華語）回覆，句子完整、唔用內部用語。Claude Code 同 Codex 都係同一個做法。

1. 呼叫工具 `ziwei_open_interface`（唔使任何參數）。唔好自己喺命令列行任何程式去開介面。
2. 呢份說明屬於天賦 1.0.6。工具結果嘅 `running` 係呢個工作階段而家運行緊嘅插件版本。工具成功（結果有 `url`）而冇 `running`，或者 `running` 低過 1.0.6，即係插件已經更新，但呢個工作階段仍然用緊舊版本：先話畀用家知新版本 1.0.6 已經安裝咗，而家打開嘅介面仍然係舊版本；請佢開一個新嘅工作階段，再輸入 `/tinfu:open`（Codex 輸入 `$tinfu:open`）就會打開新版本；唔好叫佢再更新。網址照畀，但要講明係舊版本。結果有 `installedNewer`（呢部電腦有較新嘅版本）都係咁講，版本用 `installedNewer`；如果用家話新工作階段仍然係舊版本，先至照「update」技能檢查同更新。
3. 成功嘅話，結果有 `url`（`http://127.0.0.1:…/#t=…`）：
   - 將完整網址畀用家，講明網址入面有今次嘅配對碼，只可以喺呢部電腦嘅瀏覽器打開；唔好將網址傳畀其他人。
   - `reused` 係 `true`：之前已經開咗，網址照用。
   - 介面會一直開住，直到呢個工作階段結束；之後再叫一次就會再開，網址通常唔變。
   - 如果你有打開網頁嘅工具，可以幫用家喺呢部電腦打開。
4. 結果有 `update`（有新版本），而且唔係第 2 點嘅情況：話畀用家知而家版本同新版本，問佢要唔要更新；佢話要，就照「update」技能嘅做法進行。
5. 工具回錯誤：照實講原因，唔好估。錯誤講明舊版本檔案已經移除，就直接請用家開一個新嘅工作階段，唔使再試。其他錯誤就建議用家再叫一次；仍然唔得，建議開一個新嘅工作階段再試。
6. 唔好讀取、改動或者刪除資料夾入面嘅其他檔案，亦唔好印出環境變數。
