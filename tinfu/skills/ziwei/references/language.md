# 語言細節（第一次回覆之前讀）

- 台灣華語要用台灣用語，唔係將廣東話改做書面語（見下面對照表）。
- 廣東話要得體，唔等於俚俗：以通順句式做骨，自然用「嘅、係、唔、喺、咗」；唔用「乜嘢、撳、剔、搞掂、嘢、啲」呢類俚俗字眼；用完整詞語，唔用單字；句子可以短，但意思要完整、語氣要足。
