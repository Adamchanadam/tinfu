## 序

### 初心

許多人對紫微斗數感到好奇，有人想更了解自己的性情與長處，也有人帶著生活中的實際問題而來，例如應否轉換工作、何時適合遷居或移民、怎樣與家人相處、怎樣安排自己的步伐。

我看重的，是命盤作為一套有學理脈絡的框架，可以幫助一個人有系統地認識自己。命盤把人生分為一個個十年的階段（稱為「大限」），每個階段走到命盤上不同的宮位，我把它理解為每個階段各有側重的範疇；順著這個框架，使用者可以預先設想自己在不同階段可能遇到的處境和經歷，以及自己會怎樣應對，從而提前作好準備。這個過程在某種程度上也是一次向內的反思：重新檢視自己的人生觀、價值觀和世界觀，想清楚甚麼對自己最重要。

因此，「天賦」不是用來占卜未來的。它更像程式開發時的測試計劃：把「人生旅程」看作一套系統，在每個新階段正式上線之前，先站在不同情景設想可能出現的情況，逐一準備應對方法，令自己遇上變化時仍然穩定。「天賦」希望以同樣的方式，陪伴使用者為人生的不同階段預先作好準備。

### 我的信念

我相信，命盤是一幅時間的地圖。它可以提示一些可能遇到的處境，但經驗告訴我，真正左右結果的，往往是面對處境時抱持怎樣的心態，以及預先準備了怎樣的方法。命理談吉凶，語氣往往十分肯定；我選擇把吉凶讀作對一段時間傾向的描述，並非已成定局。同一個處境，以不同的眼光看待、以不同的方法應對，結果可以截然不同。《左傳》之言：「吉凶由人。」結果的好壞，更在於一個人的心態和方法，以及怎樣修養自己看待事物的眼光。因此，「天賦」不把命盤當作定論，而是幫助使用者在處境來臨之前，先想清楚自己的心態和方法，避免落入命定論的陷阱。

古人說「觀乎天文，以察時變」，仰觀天象，為的是掌握時序、順時而行。我希望「天賦」承接這份心意：幫助使用者看清時序、及早準備，然後把決定交回使用者手中。

### 名稱的由來

「天賦」二字，本義是上天所賦予。紫微斗數依據出生的年、月、日和時辰排出命盤，以十二宮和眾星曜描述一個人的性情，以及人生各個範疇、不同時期的起伏；我著重其中的性情與長處。每個人出生的年、月、日、時，正是上天交給自己的天賦。這份天賦是人生的起點；命盤所記錄的，我把它讀作這份天賦在歲月之中怎樣展開：哪些時候適宜順勢而行，哪些時候需要多作準備。我以「天賦」為名，是希望陪伴使用者認識上天給予自己的這份禮物，看清它在時間之中的走向，再由自己決定怎樣運用。

> 上天給你的天賦，由你決定怎樣運用。

—— Adam Chan，2026 年 11 月

## 天賦一覽

### 定位

「天賦」是一部為不熟悉命理的人而設的工具，服務香港與台灣的使用者，包括移居海外的香港人與台灣人，並以廣東話及台灣華語回應。

### 特色

「天賦」以日常語言回答，並會點出相關的宮位與星曜作為理據，術語第一次出現時附上一句解釋；完整盤面可在「專業盤面」查看。使用者可以就性情、工作、財務、感情、健康與家庭等範疇提問；回答會說明機會與需要留意之處，建議現在可以先走的一步，以及今年與未來幾年可以怎樣準備，每一項準備都附有理由和具體做法。這些準備可以加入「我的準備」，日後再考慮同一範疇時會自動出現，AI 亦會一併參考。出生時間不確定，也可以透過回答幾條問題協助推算。所有資料只儲存在使用者自己的電腦。「天賦」免費使用，如覺得有所幫助，可以透過 [Ko-fi](https://ko-fi.com/adamchanadam) 捐助支持。詳情見下文常見問題。

### 使用須知

「天賦」的分析只供認識自己和規劃參考，不能代替醫療、法律、財務或心理等專業意見；所有決定由你自行作出。

## 常見問題

下文引述的按鈕名稱以書面寫法標示，廣東話介面的寫法略有不同（例如「管理已儲存嘅資料」「AI 設置」）。

### 一、開始使用

**「天賦」是甚麼？我需要懂紫微斗數嗎？**
「天賦」是一個在你自己電腦上運行的紫微斗數工具，以日常語言回答你關於性情、工作、財務、感情、健康與家庭等生活範疇的問題。你不需要懂任何命理知識：命盤畫面預設以生活範疇顯示，回答會點出相關的宮位與星曜，並附上簡單解釋；想看完整盤面，可以打開「專業盤面」。

**使用「天賦」需要甚麼？**
你需要一部電腦，安裝 Node.js 18 或以上版本，以及 Claude Code 或 Codex。如要使用介面內的「為我分析」，Claude Code 或 Codex 須以你自己的訂閱帳戶登入（Codex 用 ChatGPT 帳戶；以 API key 登入的不適用）。安裝步驟見 GitHub 頁面的安裝說明。安裝後，在 Claude Code 輸入 `/tinfu:open`，或在 Codex 輸入 `$tinfu:open`，就可以打開介面。

**介面內的「為我分析」使用哪一款 AI？**
Claude Code 和 Codex 都可以。第一次按「為我分析」時，先在「AI 設定」選擇其中一款，之後可以隨時更改。你亦可以在對話中提問：Claude Code 輸入 `/tinfu:ziwei`，Codex 輸入 `$tinfu:ziwei`。

**要付費嗎？**
「天賦」免費使用，所有功能都不需要授權碼。分析時會使用你自己的 AI 帳戶，用量計入你自己的方案。由第三次使用起，答案最後一行會出現支持「天賦」的邀請，每天最多一次；如果你覺得有所幫助，可以透過 [Ko-fi](https://ko-fi.com/adamchanadam) 捐助。

**支援哪些語言？**
介面和回答支援廣東話及台灣華語，可以在介面隨時切換，切換時已填寫的資料不會清除。在介面內用英文提問也可以，回答會用你所選的介面語言；在 Claude Code 或 Codex 的對話中，AI 會按你的用字以廣東話或台灣華語回應，分辨不到時會先問你。

### 二、出生資料與準確度

**為甚麼要填寫出生地點？**
紫微斗數按出生的時辰排盤。同一個時鐘時間，在不同地點的太陽位置並不相同，所以有出生時鐘上的時間時，「天賦」會按出生地點和日期換算為真太陽時；如果當日實施夏令時間（日光節約時間），亦會一併扣除。這些調整可能令出生時辰改變。如果按真太陽時與另一種常見排法（只扣夏令時間、不按地點校正）排出不同時辰，介面會一併列出，並可透過回答幾條問題比較哪一個較吻合。出生地點從內建的城市清單選擇，以該城市的位置計算；只記得時辰名稱或大概時段時，則不作這項換算。

**我不清楚自己的出生時間，可以使用嗎？**
可以。你可以只填大概時段，或者選擇完全不清楚，然後回答幾條關於出生時段、人生大事、家庭和性格的問題，「天賦」會按吻合程度找出最可能的時辰。結果會標明為「推算」並列出其他可能的時辰；多項經歷互相印證時，才會標示為「已核對」；資料不足時，會如實說明暫時分不出，不會勉強給出答案。涉及家庭和感情的題目會先問你是否願意回答；未滿 18 歲不會被問及人生大事和家庭。

**分析是根據甚麼？**
命盤由開源排盤程式 iztro 計算。主星亮度和五行按《紫微斗數全書》卷二的表核對（書中各處說法不一時，以該表為準）；十年階段採用現今通行的排法，由命宮起限，與《紫微斗數全書》由命宮前後一宮起限的寫法不同。性格與長處的描述，整理自《紫微斗數全書》、王亭之《中州派紫微斗數深造講義》等著作，並轉化為日常語言；只取其中描述性情的部分，書中關於富貴貧賤、壽夭的斷語，「天賦」並不採用。年份的提示按流年計算，十年主題按大限計算。

**AI 的回答準確嗎？會不會自行編造？**
「天賦」要求 AI 只根據計算出的命盤資料和整理好的性格描述作答，不可以自行加入命盤以外的資料；年份的提示由程式提供固定的字眼，AI 亦被要求照用。不過，「天賦」把命盤讀作傾向與節奏，而不當作預言；涉及健康、法律、財務等重大決定時，請同時諮詢相關專業人士。

**「天賦」會告訴我命好命壞嗎？**
不會。「天賦」不論斷命運的好壞，也不貼標籤。談到年份時，只會說明某段時間較適合主動推進，還是較需要多作準備，並為需要留意之處提供可行的準備；這些都是傾向，不是定局。

### 三、準備與時間

**答案中的「第一步」和年份準備是怎樣來的？**
年份的兩段準備，按你在時間線所選的那一年（預設是今年）及之後幾年的走勢和十年主題提出。「第一步」是一項現在就可以開始的行動建議，依據是你提出的情況和你的性格特質，而不是年份走勢。介面會在每一段旁邊註明「行動建議」或「依年份走勢」。

**「我的準備」有甚麼用？**
在回答下方按「加入我的準備」，建議就會按生活範疇整理。每一項準備都寫明理由、具體做法，以及準備好之後對你的決定有甚麼幫助。日後你在總覽選擇同一個範疇，或者在時間線看到同一年份時，這些準備會自動出現；你再就同一範疇提問時，AI 亦會參考你已準備好和尚未準備的項目，幫助你衡量決定。準備沒有限期，也不會過期，準備好之後把開關推到右邊即可。

### 四、家人、朋友與未成年人

**可以看家人或朋友的命盤嗎？**
可以。輸入資料時選擇「家人或朋友」並填寫稱呼。回答第一次提到對方時會用這個稱呼，指明是誰的命盤，避免與你自己的命盤混淆。

**未滿 18 歲的命盤有甚麼不同？**
「天賦」會按成長階段講解，不作逐年分析，不談缺點，不貼標籤，也不與其他人比較。家長或其他人查看時，建議會著重如何陪伴和配合；未成年人查看自己的命盤時，會直接以鼓勵的語氣說明自己可以怎樣發揮。未成年人的命盤不提供性格角色的分享圖片。

### 五、資料與隱私

**我的資料儲存在哪裡？會上傳嗎？**
出生資料、問答紀錄和「我的準備」只儲存在你自己的電腦之中。你按「為我分析」或在對話中提問時，相關的命盤資料、命盤主人的稱呼和年齡、你的問題，以及你之前問答的內容和「我的準備」摘要（讓回答可以延續），會交由你自己所使用的 AI 服務（Codex 或 Claude Code）分析。「天賦」沒有任何網上伺服器，亦不收集任何資料。介面只接受你這部電腦的連線，網址附有只屬於你的配對碼。如果你同時在 Claude Code 和 Codex 使用「天賦」，兩邊的紀錄分開儲存，不會互通。

**可以把資料帶到其他 AI 繼續討論嗎？**
可以。在「管理已儲存的資料」中按「匯出成檔案」或「複製全文」，就可以把出生資料、命盤、問過的問答、「我的準備」和重點整理成一份完整文件，交給其他 AI 繼續討論。從介面下載的檔案存放在「天賦」以外，之後在「天賦」刪除資料不會刪除它；在對話中請 AI 匯出的檔案則存放在「天賦」的資料夾內，刪除該人物或全部資料時會一併刪除。

**怎樣刪除我的資料？**
在「管理已儲存的資料」中，可以刪除某一位人物的全部資料，也可以按「刪除全部資料」一次刪除所有資料。刪除後無法復原，刪除前會先列出將會刪除的內容讓你確認。刪除全部資料時，「AI 設定」、支持提示的開關和使用次數，以及介面配對碼亦會一併清除；下次打開介面會用新的網址。

**檢查新版本時會傳送我的資料嗎？**
不會。「天賦」在你打開介面時最多每天檢查一次有沒有新版本，只會從公開的 GitHub 位置下載一個記錄版本號的檔案，不會傳送任何個人資料；你亦可以輸入 `/tinfu:update`（Codex 輸入 `$tinfu:update`）即時檢查。更新由 Claude Code 或 Codex 的插件市集執行，須經你同意。

### 六、其他

**如果我有傷害自己的念頭，「天賦」會怎樣回應？**
「天賦」會停止命盤解讀，改為表達關心，並鼓勵你聯絡信任的人或當地的緊急服務；在介面重新啟動或開始新對話之前，之後的提問亦不會再作解讀。「天賦」不能代替專業的支援；如果你正感到困擾，請盡快向身邊的人或專業人士求助。
